# Golden screenshots

Drop real screenshots here (PNG). The more varied, the better:

- chat room / public chat (several, including scrolled states)
- order cards (派单 cards)
- dropdown menus and settings pages
- profile pages and skill cards
- a few pop-ups and toasts

Name them descriptively, e.g. `chat_room_01.png`, `order_card_voice_test.png`.
Avoid screenshots that show bank card numbers, passwords or other private data.

The agents use these to benchmark OCR engines (Phase 1) and as regression tests forever after.
